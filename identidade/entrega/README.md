# Entrega: IDV Via Simbólica

Pacote pronto para download, gerado a partir da pasta `identidade/`:

| Arquivo | O que é |
|---|---|
| `IDV Via Simbólica.pdf` | o livro de marca em A4, com Chillax e Satoshi embutidas |
| `IDV Via Simbólica.docx` | o mesmo texto em Word (também existe como Google Doc na pasta "IDV Via Simbólica" do Drive) |
| `IDV Via Simbólica.html` | guia visual em arquivo único, com as marcas embutidas; abre em qualquer navegador |
| `Marcas Via Simbólica - SVG.zip` | todas as marcas em vetor (Via Simbólica e LiterAstro) |
| `Marcas Via Simbólica - PNG 1000px.zip` | as marcas da casa em PNG de 1000px; os de 4000px estão em `../logos/png/` |
| `Favicon Via Simbólica.zip` | favicon em 32, 48, 180, 192 e 512px, claro e escuro, e `favicon.ico` |

Regenerar: o PDF e o HTML saem de `guia.html` (Chromium); o DOCX sai de `README.md` com pandoc.
